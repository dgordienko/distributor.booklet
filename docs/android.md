# android

Приложение для планшета в торговой точке. Показывает каталог покупателю как
листаемый буклет. Kotlin, Jetpack Compose (Material 3), Navigation Compose,
Retrofit + Gson, Coil (картинки), jsoup (HTML-описания).

Приложение **только читает** данные (`GET`). Токен ему не нужен, все изменения
делаются в админке.

## Параметры сборки

| Параметр | Значение |

## Адрес сервера

Адрес backend задан константой в `data/ProductApi.kt`:

```kotlin
const val BASE_URL = "https://dswapi.online/booklet/"
```

- Слэш в конце обязателен, этого требует Retrofit. Эндпоинты относительные
  (`api/products`, `api/brand`, `api/categories`), поэтому они дописываются
  после префикса.
- Картинки приходят как `/uploads/<файл>`. `ProductApi.resolveUrl()` даёт
  `https://dswapi.online/booklet/uploads/<файл>`.
- Для локальной разработки в эмуляторе используйте `http://10.0.2.2:4000/`:
  адрес `10.0.2.2` ведёт на localhost машины разработчика.

Адрес вшит в код, поэтому для смены сервера нужна пересборка.

## Что показывается

При запуске приложение один раз загружает бренд, категории и товары. Пока
идёт загрузка, виден индикатор. При ошибке сети показывается пустой буклет:
бренд пропускается, списки пустые.

1. **Обложка** — логотип, название и слоган бренда.
2. Для каждой категории в порядке `order`:
   - **разделитель** — изображение раздела, название (заглавными) и описание;
   - **сетки товаров** этой категории по 6 на страницу, в порядке товаров
     внутри категории. На плитке главное фото, название и тип товара.
3. **Товары без категории** — в конце, без разделителя.

Показываются только товары с `isActive = true`. Тап по плитке открывает
полноэкранную карточку товара: торговая марка, производитель, название, срок
и температура хранения, состав, описание и цена с валютой. Карточки можно
листать. Каждый товар в этом режиме встречается один раз, даже если он входит
в несколько категорий.

## Сборка и запуск

```bash
cd android
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"   # если в PATH JDK < 17
./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:compileDebugKotlin
```

Или откройте папку `android/` в Android Studio и запустите конфигурацию `app`.

## Известные ограничения

- **Команды не учитываются.** В админке категорию можно привязать к командам
  («свой каталог на команду»), но планшет об этом не знает: в модели
  `Category` нет `teams`, фильтрации нет. Все устройства показывают все
  категории.
- **Нет обновления без перезапуска.** Данные загружаются один раз при старте,
  кеша и офлайн-режима нет.
- **Включён `usesCleartextTraffic="true"`.** Для продакшена по HTTPS он не
  нужен, его оставили ради локального `http://10.0.2.2:4000/`. Для релизной
  сборки его стоит выключить.
- **Release-сборка не настроена:** нет `signingConfig` и отдельных
  `buildTypes` и `flavors` с разными адресами сервера. Unit-тестов пока нет.
